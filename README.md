Weather Station

A clean, single-file weather app that shows real-time conditions for any city. Built with plain HTML, CSS, and JavaScript, powered by the OpenWeatherMap API.

Features:
- City-based search — look up current weather for any city in the world
- Use my location — one-tap geolocation search for local weather
- Dynamic weather icons — icon updates to match live conditions
- Temperature dial — animated gauge showing temperature at a glance
- Key stats — humidity, wind speed, pressure, visibility, sunrise & sunset
- °C / °F toggle — switch units instantly, no extra API call
- Responsive design — works on desktop and mobile
- Enter-key search — press Enter or tap the button, both work
- Friendly errors & loading states — clear feedback if a city isn't found or the network drops
